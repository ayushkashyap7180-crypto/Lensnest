# LensNest 📸

**Find images that bring your ideas to life.**

LensNest is a web-based image discovery project that provides a simple interface for searching and exploring images. It features a search area and a responsive grid layout for displaying image results.

## ✨ Features

- 🔍 **Image Search** — Search for images using the search field.
- 🖼️ **Image Gallery** — Display image results in a clean grid layout.
- 📱 **Responsive Design** — Adapt the interface to different screen sizes.
- 🎨 **Modern UI** — Enjoy a clean design with a purple-themed color palette.
- ⚡ **Interactive Elements** — Hover effects and interactive search controls.

## 🛠️ Technologies Used

- **HTML5** — Structure of the web application.
- **CSS3** — Styling, responsive layouts, and hover effects.
- **JavaScript** — Search functionality and dynamic image results.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ayushkashyap7180-crypto/Lensnest.git
```

### 2. Open the project folder

```bash
cd Lensnest
```

### 3. Run the project

Open `index.html` in your web browser, or use the **Live Server** extension in Visual Studio Code.

## 💡 How to Use

1. Open the LensNest website.
2. Enter a search term in the image search field.
3. Click the **Search** button.
4. Explore the displayed image results.
